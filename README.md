# 찰나 (CHALNA)

> **0.03초의 완벽을 쫓아라** — 한 번의 탭으로 도파민을 자극하는 하이퍼캐주얼 타이밍 게임

바늘이 다이얼을 돌며 빛나는 목표 아크를 향해 갑니다. 바늘이 **금색 띠**를 지나는 찰나에 탭하세요.
퍼펙트를 이어갈수록 배율이 오르고, 효과음의 음정이 반음씩 올라가고, 8연속이면 **피버**가 터집니다.
미스하면 게임 오버 — 대신 몇 밀리초 차이로 놓쳤는지 정확히 보여줍니다. *"0.017초 늦었어요!"*

## 플레이 방법

`index.html` 하나가 게임의 전부입니다. 브라우저에서 열기만 하면 됩니다.

```bash
# 로컬에서 바로 열기
open index.html          # macOS
xdg-open index.html      # Linux

# 또는 아무 정적 서버로
npx serve .
```

| 입력 | 동작 |
|---|---|
| 탭 / 클릭 / `Space` / `Enter` | 시작 · 판정 · 재시작 (전부 이 하나) |
| `M` 또는 우상단 스피커 아이콘 | 음소거 |
| 좌상단 `‹` 아이콘 | 메뉴로 돌아가기 (플레이 중에도 언제든) |

## 모드

메인 화면에서 카드를 탭해 선택합니다. 데일리 챌린지와 도감은 **Lv.2**부터 열립니다.

| 모드 | 설명 |
|---|---|
| **클래식** | 원조 엔드리스 모드. 레벨이 오를수록 새 아크 변형이 하나씩 풀립니다. 자신의 최고 기록 고스트 바늘과 함께 달립니다. |
| **데일리 챌린지** | 오늘 날짜로 시드된 아크 시퀀스 — 전국 모든 플레이어가 오늘 같은 순서의 도전을 받습니다. 무제한 재도전, 연속 플레이 일수 추적. |
| **젠 모드** | 60초 타이머, **죽지 않는** 연습 모드. 미스해도 굿처럼 스트릭만 리셋되고 게임은 계속됩니다. |
| **도감** | 레벨/XP, 코인, 업적 18종, 테마·트레일 코스메틱, 설정(모션 줄이기·고대비 색상)을 한곳에서 관리합니다. |

## 판정 규칙

| 판정 | 조건 | 결과 |
|---|---|---|
| **퍼펙트** | 금색 띠 안에서 탭 | `+25 × 배율`, 스트릭 +1, 히트스톱 + 골드 폭발 |
| **굿** | 시안색 존 안에서 탭 | `+10 × 배율`, **스트릭·배율 리셋** — 살아남지만 아픕니다 |
| **미스** | 존 밖에서 탭 | 게임 오버. 몇 ms 차이였는지 슬로모션으로 보여줌 |

- **배율**: 연속 퍼펙트 3/6/10/15회에서 ×2/×3/×4/×5
- **피버**: 8연속 퍼펙트마다 6초간 전체 점수 ×2 + 퍼펙트 띠 20% 확대
- **골드 아크**: 10타 이후 1/8 확률로 등장, 퍼펙트 시 ×3 잭팟
- **10타 마일스톤**: 매 10타마다 +50
- 히트마다 바늘은 **방향을 반전**하고 점점 빨라집니다 (200 → 460°/s, 퍼펙트 창은 최종 30ms까지 수축)

## 아크 변형 (레벨로 해금)

클래식·데일리·젠 모드 공통으로, 레벨이 오르면 새로운 아크 유형이 섞여 들어옵니다.

| 아크 | 해금 레벨 | 설명 |
|---|---|---|
| **동요** | Lv.3 | 퍼펙트 존 중심이 좌우로 흔들립니다 — 위치와 타이밍을 동시에 맞춰야 합니다 |
| **수축** | Lv.5 | 바늘이 다가올수록 금색 띠가 실시간으로 좁아집니다 |
| **디코이** | Lv.8 | 진짜 아크 앞에 점선으로 표시된 가짜 아크가 나타납니다 — 탭하면 즉시 미스 |
| **체인** | Lv.12 | 3연속 미니 아크. 셋 다 퍼펙트로 이어가면 대형 보너스 "체인!" 완성 |

## 성장 · 코스메틱

- **XP·레벨**: 매 판마다 점수/퍼펙트 수에 비례해 XP 획득, 레벨업마다 새 아크 유형과 테마가 해금됩니다
- **코인**: 플레이만으로 모입니다 (구매·과금 없음). 도감에서 테마·트레일을 조기 해금하는 데만 사용
- **업적 18종**: 첫 퍼펙트부터 데일리 7일 연속까지, 달성 시 토스트 알림 + 도감에 영구 기록
- **고스트 리플레이**: 클래식 모드에서 자신의 최고 기록 바늘을 옅게 겹쳐 보여줍니다 — 판정에는 영향 없는 순수 시각 효과
- **테마 4종 · 트레일 3종**: 색상 팔레트는 항상 시안(굿)·골드(퍼펙트) 조합을 유지해 색맹에도 안전합니다. 고대비 "모노" 테마 포함

## 특징

- **단일 HTML 파일** — 외부 의존성 0, 네트워크 요청 0. 사운드는 WebAudio로 실시간 합성, 그래픽은 Canvas 2D
- 모바일 터치 최적화 (줌/스크롤/길게누르기 차단, 진동 피드백)
- 스트릭에 따라 반음씩 상승하는 차임, 니어미스 ms 표시, 최고 기록 접근 시 심장박동 연출, 실시간 신기록 순간
- 모든 진행 상황(점수·레벨·코인·업적·데일리 스트릭·고스트)을 `localStorage`에 저장, 이전 버전 세이브 자동 이전
- **다크패턴 없음** — 실제 현금 결제, 확률형 뽑기, 에너지/재화 제한 없이 오직 플레이로만 모든 것을 얻습니다

## 왜 이 게임인가

5개의 경쟁 컨셉(타이밍/연쇄반응/푸시유어럭/플로우/정밀쌓기)을 행동심리학·하이퍼캐주얼 프로듀싱·게임필 엔지니어링 관점의 심사로 채점한 결과, 만장일치로 선정된 디자인입니다. 도파민을 자극하는 장치는 전부 **게임필**에서 나옵니다 — 과금·도박·다크패턴 없이, 변동 보상(골드 아크), 니어미스 효과(ms 단위 아쉬움), 손실 회피(스트릭 리셋), 목표 접근 효과(신기록 심장박동)를 순수하게 플레이로 구현했습니다.
