# 찰나 (CHALNA)

> **0.03초의 완벽을 쫓아라** — 한 번의 탭으로 도파민을 자극하는 하이퍼캐주얼 타이밍 게임

바늘이 다이얼을 돌며 빛나는 목표 아크를 향해 갑니다. 바늘이 **금색 띠**를 지나는 찰나에 탭하세요.
퍼펙트를 이어갈수록 배율이 오르고, 효과음의 음정이 반음씩 올라가고, 8연속이면 **피버**가 터집니다.
미스하면 게임 오버 — 대신 몇 밀리초 차이로 놓쳤는지 정확히 보여줍니다. *"0.017초 늦었어요!"*

## 플레이 방법

`index.html` 하나가 게임의 전부입니다. 브라우저에서 열기만 하면 됩니다.

```bash
# 로컬에서 바로 열기
open index.html          # macOS
xdg-open index.html      # Linux

# 또는 아무 정적 서버로
npx serve .
```

| 입력 | 동작 |
|---|---|
| 탭 / 클릭 / `Space` / `Enter` | 시작 · 판정 · 재시작 (전부 이 하나) |
| `M` 또는 우상단 스피커 아이콘 | 음소거 |

## 판정 규칙

| 판정 | 조건 | 결과 |
|---|---|---|
| **퍼펙트** | 금색 띠 안에서 탭 | `+25 × 배율`, 스트릭 +1, 히트스톱 + 골드 폭발 |
| **굿** | 시안색 존 안에서 탭 | `+10 × 배율`, **스트릭·배율 리셋** — 살아남지만 아픕니다 |
| **미스** | 존 밖에서 탭 | 게임 오버. 몇 ms 차이였는지 슬로모션으로 보여줌 |

- **배율**: 연속 퍼펙트 3/6/10/15회에서 ×2/×3/×4/×5
- **피버**: 8연속 퍼펙트마다 6초간 전체 점수 ×2 + 퍼펙트 띠 20% 확대
- **골드 아크**: 10타 이후 1/8 확률로 등장, 퍼펙트 시 ×3 잭팟
- **10타 마일스톤**: 매 10타마다 +50
- 히트마다 바늘은 **방향을 반전**하고 점점 빨라집니다 (200 → 460°/s, 퍼펙트 창은 최종 30ms까지 수축)

## 특징

- **단일 HTML 파일** — 외부 의존성 0, 네트워크 요청 0. 사운드는 WebAudio로 실시간 합성, 그래픽은 Canvas 2D
- 모바일 터치 최적화 (줌/스크롤/길게누르기 차단, 진동 피드백)
- 스트릭에 따라 반음씩 상승하는 차임, 니어미스 ms 표시, 최고 기록 접근 시 심장박동 연출, 실시간 신기록 순간
- 최고 점수·최고 연속 퍼펙트·누적 퍼펙트를 `localStorage`에 저장

## 왜 이 게임인가

5개의 경쟁 컨셉(타이밍/연쇄반응/푸시유어럭/플로우/정밀쌓기)을 행동심리학·하이퍼캐주얼 프로듀싱·게임필 엔지니어링 관점의 심사로 채점한 결과, 만장일치로 선정된 디자인입니다. 도파민을 자극하는 장치는 전부 **게임필**에서 나옵니다 — 과금·도박·다크패턴 없이, 변동 보상(골드 아크), 니어미스 효과(ms 단위 아쉬움), 손실 회피(스트릭 리셋), 목표 접근 효과(신기록 심장박동)를 순수하게 플레이로 구현했습니다.
